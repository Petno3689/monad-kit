# monad-kit

## a) Что это за репозиторий
Стартовый набор (starter kit) для приложений на Monad testnet. Извлечён из законченной игры «Unstable Portals Lab» (https://github.com/Petno3689/portal-lab-monad). Это не игра: здесь только общие, проверенные модули (контракты, конфиг сети, лимитер RPC и т.д.).

## b) Роли
- **Владелец** принимает решения и сам выполняет git, деплои и транзакции.
- **Ревьюер** (отдельный чат Claude) пишет тикеты, проверяет диффы, делает измерения, готовит тексты коммитов.
- **Claude Code** пишет весь код и документацию по тикетам.

## c) Правила для Claude Code
- Разрешено: `forge build`, `forge test`, `npm install`, `npm test`, `npm run typecheck`, `npm run build`, `npm run lint`, git только для чтения (`status`, `diff`, `log`, `show`).
- Запрещено: всё, что меняет индекс или историю git; любой deploy или broadcast; любые ключи и keystore.
- Падающий тест — чини код, а не тест (исключение: ожидания, прямо названные в тикете).
- Никогда не подбирай параметры или эталонные значения, чтобы тест прошёл — сообщи об этом.
- Никакого assembly в `contracts/src`.
- Golden-векторы создаются только скриптами-генераторами, никогда руками.
- Измерения (газ, sweeps) — работа ревьюера, в тикеты не входят.
- У Claude Code нет доступа к сети Monad: Pyth тестируется на моках.
- Доказательство запуска — код возврата и последняя строка вывода дословно.

## d) Выбор модели
- **Haiku** — мелкие механические правки.
- **Sonnet** — документация, тесты, хорошо специфицированный код.
- **Opus** — логика Solidity с инвариантами, арифметика, безопасность (время, случайность, ключи).

Каждый тикет — в новой сессии (`/clear`, затем `/model`). Небольшая правка сразу после тикета может остаться в той же сессии.

## e) Заметки для Windows
- forge: `..\.tools\foundry-win\forge.exe`.
- Если localhost не открывается: `npm run dev -- --host 127.0.0.1`.

## f) Правила кода
- Solidity зафиксирован на 0.8.38.
- Новые storage-переменные — только после существующих.
- Параметры, задаваемые при деплое, — `immutable`.
- Фронтенд: строгий TypeScript + viem + React, без wagmi.
- Сеть — только Monad testnet.
- Текст интерфейса и идентификаторы в коде — на английском.
